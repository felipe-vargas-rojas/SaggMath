We introduce the notion of Declarative Data Groups (DDGroup). A DDGroup defines the way instances can be assigned to groups given a set of conditions. For example, experimental observations can be grouped by type of sensor or area. This novel concept empowers the declaration of various types of groups. Group declarations are stored alongside the data and invoked via a query. This notion of groups permits to execute aggregate functions concerning the members belonging to a declared group.
