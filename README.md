# SaggMath validation 

SaggMath is implemented based on QAVAN. This package contain two folders:

- "data_preparation" correspond to a set of scripts dedicated to transform CSV data to the target model, particullarly SOSA. 
- "SAggMath_test" contains a SHACL shape to extend the QAVAN' logic. That new functions enable groups and aggregations. Additionally, it presents inputs to run the aggregation model.
